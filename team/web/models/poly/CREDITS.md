# Models from Poly Pizza

Downloaded from [poly.pizza](https://poly.pizza) as GLB; the file names are ours. Changes: the embedded textures of `bulldozer.glb` (2048 → 512 px) and `silos.glb` (1000 → 256 px) are scaled down, so the WebGL scene stays light without a GPU. The other models are unchanged.
